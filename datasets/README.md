# Dataset staging

`raw/` is for source-preserving imports and `processed/` for versioned, normalized splits. Both directories ignore their contents by default to prevent accidental publication of private or unlicensed data.

Every imported source must record: source URL/owner, retrieval date, license, permitted uses, checksum, schema, language, deduplication method and removal requests. Never scrape or publish personal bodim reviews without a lawful basis and documented consent.

The checked-in fixtures and `smart_bodim_search_pairs.jsonl` are intentionally synthetic CC0 academic inputs. They contain no personal data and must not be presented as a real-world benchmark. The submitted domain dataset has a deterministic processed split and SHA-256 manifest under `processed/smart-bodim-v1`.

## What this submitted project actually uses

| Data | Size | Used for | Status |
|---|---:|---|---|
| Seeded public listing corpus | 24 individually written listings across 24 Sri Lankan areas, with 24 distinct local images | Chatbot retrieval, filters, recommendations and search indexing | Synthetic application data generated by Laravel's seeder; images were generated specifically for this project and are not scraped property photos |
| `catalog/sri_lanka_higher_education_destinations.json` | 160 physical destinations: 152 higher-education locations across 41 organizations and 8 workplaces | Runtime destination resolution and reproducible dataset generation | UGC/Ministry scope plus official institution branch directories; online-only centres excluded |
| `smart_bodim_search_pairs.jsonl` | 7,680 query/positive/hard-negative triples across 1,920 intent groups and 160 destinations | Domain fine-tuning for branch-aware campus/workplace, price, radius, property, facility and accommodation-rule intent | Checked-in CC0 synthetic academic dataset; deterministic group-aware 5,376/1,152/1,152 split |
| `query_intent_examples.jsonl` | 960 multilingual examples across 160 destination-held-out groups | Trains `query-intent-v1` to calibrate English, Sinhala, Tamil and Singlish intent labels | Checked-in CC0 synthetic academic data; character n-grams preserve native scripts without sending text to an external service |
| `fixture_search_pairs.jsonl` | 3 query/relevance pairs | Reproducible search evaluation and training-pipeline smoke test | Checked-in CC0 synthetic fixture |
| `fixture_reviews.jsonl` | 5 labelled reviews | Sentiment/aspect evaluation and training-pipeline smoke test | Checked-in CC0 synthetic fixture |

`evaluation/` documents the consented human-evaluation queue. Tenants must explicitly donate a query; Laravel removes phone, email and identity-number patterns before storage. Administrators add corrected slots and relevance order. These samples are the only valid basis for future real-user Recall, NDCG, calibration or language-slice claims.

The running chatbot searches the current published listing corpus in the database using the fine-tuned sentence-transformer ranker. All wording variants in one intent group remain in one split, preventing query paraphrases from leaking across training, validation and testing. Every official physical branch in a multi-site network is represented separately; hard negatives deliberately use a wrong branch from the same organization, exceed the budget and omit a required facility. The held-out evaluation remains synthetic academic evidence, not a production benchmark. No Kaggle dataset is bundled or claimed.

Generate the destination catalog with `ai-service/generate_institution_catalog.py`, generate domain data with `generate_domain_dataset.py`, validate it with `validate_dataset.py`, and create the reproducible split with `prepare_data.py`. Institution records store their official directory or regulatory source. Coordinates marked `town-reference` support transparent approximate distance comparisons and must not be described as live routing or exact gate coordinates. All accommodation wording is synthetic CC0 project data and contains no personal information.

Required review schema: `id`, `text`, `label`, `source`, `license`. Required search-pair schema: `id`, `query`, `positive`, `negative`, `source`, `license`. A production import adapter must preserve original IDs/provenance, normalize text without erasing meaning, group duplicates before splitting and record any removal/legal constraints.

Nearby-place fixtures cover bus, rail, supermarkets/Cargills, hospitals, food, pharmacies, banks/ATMs, police and laundry. API records include provider, verification time and coordinate-confidence fields. Fixture coordinates are approximate project evidence, not a claim that a business is currently open.
